# CareFlow Replay Data

`bidmc_25_careflow.csv` is a normalized demo replay file derived from the BIDMC PPG and Respiration Dataset v1.0.0 on PhysioNet:

https://physionet.org/content/bidmc/1.0.0/

The source dataset is distributed under the Open Data Commons Attribution License v1.0. This derived replay file should keep attribution to the BIDMC dataset, PhysioNet, and the original publication cited by PhysioNet.

CareFlow adds a demo HRV proxy and `anomaly_flagged` values for replay/testing. These additions are not clinical labels.
